# 首次公开发布检查表

## 本机整理

- 私人数据仅放在被忽略的 `data/`、`private/`；历史调研、真实验证记录与旧截图不进入公开包。
- `.upstream/` 不发布。历史单机迁移与修复脚本不进入公开包。
- 文档、示例、测试、Issue 附件不含真实联系人、微信标识、密钥、本机个人路径或真实聊天。
- 模型默认未配置；自动微信读取和模型整理默认关闭。MIT 仅覆盖本项目代码，第三方保留自身许可。

## 验证与打包

1. 运行 README 中的离线测试、前端语法检查、`check_release.py`。
2. 运行 `build_release.py`，解压到新目录，用未配置的独立数据目录启动，验证无账号也能导入、编辑记忆和查看预览。
3. 核对 ZIP 清单；安装开发工具 `python -m pip install detect-secrets==1.5.0`，运行 `python scripts/scan_secrets.py`，再人工检查文档、样例。扫描只复制公开候选文件到临时目录，不扫描私人目录、不联网验证密钥，也不保证发现所有秘密。
4. 真正调用模型前，用虚构数据检查配置、外发预览和失败提示；这一步可能产生费用，不属于离线 CI。

## GitHub 发布（另行执行）

确定仓库名称、所属账号和可见性后再创建。首次提交前检查 `git status --short`、暂存文件列表和 `git diff --cached`，不要添加未审阅的文件。若已有提交，检查完整历史，不能只看工作区。

开启 GitHub 私密漏洞报告；确认 CI 在 Python 3.11/3.13 Windows 通过，再创建 `v0.1.0` 标签和实验版 Release。

本阶段生成源码发布候选包，不自动创建仓库、提交、推送或打标签。本机验证见 [验证记录](validation.md)。
