# 能力范围与兼容性

| 能力 | v0.1.0 证据与限制 |
| --- | --- |
| JSON 导入、去重、时间与发送者 | 虚构夹具的离线测试通过；未知发送方向需人工核对。 |
| 联系人隔离、记忆纠错和旧摘要停用 | 离线测试覆盖；证据范围校验不等于模型语义正确。 |
| 日期补齐和连续批次 | 测试覆盖包含首尾日期、中断续跑、完整成功后推进检查点。 |
| 微信读取 | 可选 WeFlow CLI 1.9.0 子进程；曾在单台 Windows / 微信 4.1.15.13 验证，不保证所有版本。 |
| 通用模型 API | 实现 Chat Completions 协议，测试用模拟 HTTP；此次发布整理未逐家验证真实供应商。 |
| Codex CLI | 可选本机入口；开发验证环境曾使用，不保证所有账户、CLI 版本或模型可用。 |
| 自动记忆 | 每日检查点，授权后更新人物/关系摘要和事件记忆；大历史需要多批外发。 |
| 读屏、悬浮窗与多端 | 仅预留接口，未实现。 |

本轮开源整理未重新读取私人微信或调用真实模型。以前的真实样本记录与截图保留在本机私有目录，不作为可公开复现实验数据。公开演示从零编造，不由真实聊天替换姓名生成。

当前最小组合为 LoveShe 核心 + 自选模型；需要微信更新时增加 WeFlow。其他调研项目不作为运行依赖，来源见第三方说明。
