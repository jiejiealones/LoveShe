# 数据、授权与删除

默认数据目录是源码工程的 `data/`；`LOVESHE_DATA_DIR` 可覆盖。目录含 SQLite、模型配置、原始导出、备份、联系人记忆及更新记录。该目录与 `private/` 排除版本控制，但用户仍应检查自己创建的导出文件位置。

## 数据流

1. 浏览器只访问本机回环地址。聊天导入、检索、统计、记忆编辑在本机完成，不调用模型。
2. 咨询和回复建议先展示拟发送内容；确认后将选定联系人的原文、档案、相关记忆、摘要及相关咨询/反馈发送到配置的模型服务。
3. 自动整理须按联系人开启并同意持续外发范围。第一次处理大量历史可能连续多批调用、产生费用或消耗额度。更换模型配置后须重新授权；查看更新记录可核对实际外发内容。
4. 微信轮询通过本机 WeFlow 工具读取，首次执行可能访问 npm 下载程序。WeFlow 的数据处理和初始化行为另见其上游文档。
5. 应用不会自动向微信联系人发送消息；用户自行修改、复制和发送回复。

## 自动化

全新联系人默认不监听、不自动更新记忆。启用后，服务和微信必须运行；关闭浏览器不等于关闭服务。关闭服务或暂停自动设置会阻止后续处理，不能撤回已经发出的模型请求。

自动记忆按北京时间每日检查：先补齐上次完整检查点到今天的聊天，逐批完成后推进检查点；未完成区间可续跑。同日新增内容可手动“更新记忆到今天”。自动条目允许合并时会记录版本，手工保存或纠正的记忆受保护。

## 保存和删除

- SQLite、模型密钥与导出文件**没有应用层加密**。配置向导会尝试设置文件权限，但 Windows 上不提供额外的 ACL 隔离；使用本机账户和磁盘保护。
- 模型调用会留下本地外发范围、结果与更新审计，其中可能包含原文；反馈、旧记忆版本和旧摘要也属于私人数据。
- 删除联系人会删除应用中该联系人的数据和生成的联系人目录；已经单独保存的原始导出、下载文件和完整数据库备份不会随之删除。
- 手工纠正或删除记忆会停用旧摘要与旧追问上下文；历史原文、历史版本和既往咨询并不等同于被清除。需要彻底清除时删除联系人并另行清理导出与备份。
- 本地删除不能删除模型服务已接收的数据；保存时限和训练使用规则由所选服务决定。发送前自行核对其条款。

本服务设计用于单人本机使用，不提供公网、多用户认证或局域网部署能力。关系分析是参考意见，模型不能知道对方未表达的真实心理；证据 ID 校验也不能保证结论语义正确。
